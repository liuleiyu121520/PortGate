# PortGate 现 UI 视觉问题盘点（image-analyst，V1.1 UI 重构需求输入）

> 来源：用户截图（Midnight Slate 暗色主题，2560×1600，可见 9 行/共 122 行）
> 结论：装饰比数据响亮——红按钮墙与三色徽标堆叠锁死视觉焦点，128px 松散行高、全空 PROJECT 列与右侧死空间使数据难扫读。

## P0
1. 「结束」按钮红描边墙：9 行中 8 行重复红色描边按钮，破坏性操作强调失控 → 默认中性/hover 才升格红色
2. PORT 列徽标纵向堆叠（UDP/TCP 徽标+大号端口号+Exposed 徽标三层、三配色）→ 压单行、色彩减到 0-1 种
3. ADDRESS 列换行肢解地址（"198.18.0.1:51544-" / ">198.18.0.33:443"）→ 禁止断词换行，"->" 改 "→"
4. 行密度过低（行高约 128px）+ PROJECT 列全空 + ACTION 右侧约 470px 死空间 → 行高压到 48-60px、列宽回收

## P1
5. 列宽与内容权重错配（PORT 列 364px 只放 60px 内容）
6. 状态色过多（绿/蓝/琥珀/红四强调色，蓝、琥珀各自多处复用不同含义）→ 品牌蓝 + 语义色两层色板
7. 标题重复（系统标题栏 + 应用内页眉同文案），页眉 90px 只放标题 → titleBarStyle hiddenInset 合并
8. 中英文混排无策略（表头英文大写/按钮中文/统计英文标签）
9. 数字未用等宽/表格数字；"· 22415"（PID）与 "· LISTEN"（状态）中点后缀语义混用
10. 禁用态结束按钮（ControlCenter 行）无解释、对比度低
11. 行分隔三重叠加（斑马纹+分隔线+外框卡片）互相稀释 → 只留一种

## P2
12. 次要文本对比度普遍偏低（PID/LISTEN/占位符/主题名/Monitoring）
13. 控件圆角/描边语言不统一（搜索框胶囊 vs 徽标 6px vs ⌘K 键帽另一套）
14. Tab「当前」后有疑似文本光标残影 → user-select: none
15. 统计行层级松散，琥珀 "27" 提前抢焦点
16. 主题开关+主题名占页眉黄金位
17. 文案细节："2m0s"→"2m"、"..."→"…"、"->"→"→"
