## 1. 背景与用户原话

用户原话：**「UI效果太差，使用 apple 设计风格」**。

追加反馈（2026-09-23，主理人转达，UI 重构交付后回流）：**「这些指标应该在下方弄个字号小一点、颜色浅一些的字体标注中文意思，相当于指标都需要中英文两个同时显示——因为计算机专业角度都用英文，但有时候不认识时可以借助中文理解」**（附旧版全英文表头与 Drawer 标签截图，认可值层「Local · 仅本机」双语形态）。该反馈经实施方案 v1.2 §11.5 语义守卫登记并审查闭环后，由 PM lane 同步至本记录（§6 文案策略、§7 UI-AC-22、§8 D-UI-10）。

V1 功能全部交付并通过 AC-01~AC-16 验收，但视觉层存在系统性问题（盘点结论：装饰比数据响亮——红按钮墙与三色徽标堆叠锁死视觉焦点，128px 松散行高、全空 PROJECT 列与右侧死空间使数据难扫读）。本次重构以 Apple 设计语言为唯一视觉规范，对 PortGate（数据密集型桌面工具）做密度适配后全量落地。

已确认约束（主理人转达，2026-09-23）：
- 功能与信息架构不变：搜索/列表/详情/终止/历史/设置全部保留，AC-01~AC-16 不得回退（尤其 HighlightText 唯一高亮、双主题、⌘K）
- 只动视觉与交互层（样式、布局密度、控件形态、文案规范化），不改 IPC 契约、数据语义、安全边界
- 双主题必须保留，色板按 Apple 语言重新定义（明=白/羊皮纸系，暗=近黑 tile 系，强调色统一 Action Blue 系）——构成对基线 §23 色值的有意变更
- 用户偏好暗色主题（截图为暗色），重构后**暗色必须是第一观感达标项**

## 3. 范围

### 3.1 范围内

1. 设计 token 体系落地（双主题色板、字体栈、字重梯、负字距、圆角档、hairline、间距、焦点环、按压态）
2. 页眉整合：消除双标题（macOS hiddenInset）、页眉控件收敛（主题开关图标化、监控状态点保留）
3. 搜索框形态 pill 化（⌘K 行为不变）
4. 统计条层级重排与语义色规则
5. 主表格重构：行密度、PORT 列单行化、ADDRESS 不断词、PROJECT 列策略、行分隔唯一化、操作列收缩、结束按钮状态语法（中性→hover 红→确认红）
6. Tab / Drawer / 确认弹窗 / 空态 / 禁用态等组件形态按 Apple 语法统一
7. 文案规范化（中英文规则 + 格式细节，§6）
8. 全部非禁用文本对比度达 WCAG AA（≥4.5:1）
9. 交互微反馈：按压 scale(0.95)、2px 焦点环（应用内控件）

### 3.2 范围外（防蔓延清单）

1. **应用图标**（Dock/Finder icon）——另走方案 §11 D-3 ICON-ARRIVAL 流程，与本次无关
2. **任何功能与 IA 变更**：搜索语法/字段/权重、终止与保护流程、历史能力、设置项集合、IPC 契约、数据语义、安全边界（§15~§18）一律不动
3. Win/Linux Adapter 完整实现、打包（electron-builder 配置除窗口外观项外）、CI 变更
4. Apple 响应式断点体系；仅要求架构师定义窗口 min/max 尺寸下的合理布局
5. 动效体系扩展（仅保留规范内微交互，不引入营销页滚动/视差动效）
6. 新增运行时依赖非强制（如 Inter 字体包由架构师按跨平台回退需要裁定）
7. 技术栈更换（§20 不变）；antd 如何达成视觉目标（ConfigProvider token 定制 / 组件级覆盖 / 个别组件自绘替换）属架构师实现裁定
8. 营销页专属模式：全幅 tile、80px section 留白、摄影类阴影

## 4. 设计 token 映射与密度适配裁定

### 4.1 色板（对基线 §23 的有意替换，用户-directed）

**明色主题（主题名：浅色）**

| Token | 值 | 来源/用途 |
|---|---|---|
| 画布 canvas | `#ffffff` | 主工作区、表格、抽屉 |
| 次级面 surface | `#f5f5f7` | 页眉/统计条带、次级区块（羊皮纸） |
| 正文 ink | `#1d1d1f` | 全部正文与标题 |
| 次要文本 muted | `#6e6e73` | 次要/辅助文本（DESIGN.md 体系内 Apple 实产次要灰，于 #fff 与 #f5f5f7 上均 ≥4.5:1） |
| hairline | `#e0e0e0` | 全部 1px 分隔线与描边 |
| 强调 accent | `#0066cc` | 全部交互元素（链接、选中、主按钮、焦点根） |
| 焦点环 focus | `#0071e3` | 键盘焦点 2px outline |

**暗色主题（主题名：深色，第一观感达标项）**

| Token | 值 | 来源/用途 |
|---|---|---|
| 基底 base | `#252527` | 窗口底色（tile-3） |
| 主表面 surface | `#272729` | 表格/卡片/抽屉（tile-1） |
| 抬升面 surface-2 | `#2a2a2c` | hover 面、浮层、次级条带（tile-2） |
| 正文 on-dark | `#ffffff` | 正文与标题 |
| 次要文本 muted | `#cccccc` | 次要/辅助文本 |
| hairline（暗） | 由架构师自 tile 系派生（如白色低透明阶），须经 UI-AC-09 对比度断言 | 分隔线 |
| 强调 accent | `#2997ff` | 暗面全部交互元素（Action Blue 系暗面变体，对 #272729 对比 ≈4.9:1） |
| 焦点环 focus | 架构师在 #2997ff 基础上定（须可辨识） | 焦点 outline |

**语义色（唯一含义映射，对盘点 P1-6 的裁定）**

| 语义 | 唯一含义 | 明/暗值 | 架构师约束 |
|---|---|---|---|
| Danger 红 | 破坏性操作确认、保护拒绝（System Protected） | 架构师定（可沿用 #E5484D 或对齐系统红） | 文本用途对比 ≥4.5:1；仅此一处含义 |
| Warning 琥珀 | 仅「对外暴露（Exposed）」一种含义，且仅 Exposed>0 时出现 | 架构师定 | 同上；不得复用于统计、Pending 等其他语义 |
| Success 绿 | 仅「监控运行中」状态点一种含义 | 架构师定 | 非文本 UI 元素对比 ≥3:1 |

- 品牌蓝**只承担交互语义**，不再作任何状态色；琥珀在 V1 中的一切其他用法全部移除。
- 明暗两主题各出一张完整 token 表（含 hover/active/禁用/disabled 派生阶），由架构师在 `styles/variables.less` 固化，token 名与 DESIGN.md YAML 键对齐。

### 4.2 字体与排版

- 字体栈：`system-ui, -apple-system, BlinkMacSystemFont, "SF Pro Text", sans-serif`（macOS 解析为 SF Pro；跨平台回退按 DESIGN.md 替代字体指引，Inter 为可选项非强制）
- 字重梯：**300 / 400 / 600 / 700，禁止 500**（硬约束）
- 页面级标题（页眉应用名）：Display 语法——600 + 负字距（-0.2px 级，具体值架构师定档）
- 数据密集面（表格/统计/抽屉正文）：**基准字号 13px 档**（±1px 由架构师定档），层级用字重 400/600 与次要色区分；正文行高不得低于 1.4
- 数据指标标签中文辅助行（v1.1 双语标注，§6-3/§6-9）：**11px/400、次要文本色**——用户-directed「字号更小、颜色更浅」方向的架构师定档；不入上条「基准字号 13px 档」断言域（该域度量对象为数据面正文字号），「更浅」由 11px+400 相对主行的视觉重量差与次要文本色共同承担（次要文本 token 双主题均 ≥4.5:1，复用既有 token、无新色值）
- 数字：PORT / PID / UPTIME / 统计数字一律 `font-variant-numeric: tabular-nums`（硬约束）
- 键帽（⌘K）与徽标属于控件，不独立造轮子，映射到 §4.3 圆角档

### 4.3 形状与层次

- 圆角档（硬约束，全控件收敛）：`5px`（键帽、小徽标）/ `8px`（次级 utility 按钮）/ `11px`（胶囊外次级控件、抽屉内嵌块）/ `18px`（卡片、Drawer 面板）/ `pill 9999px`（主按钮、搜索框、Tab 容器、option chip）/ `0`（仅全幅条带）
- hairline：全部分隔与描边统一 1px hairline token；禁止多重描边
- 层次：表面色变化 + hairline + 浮层 scrim 承担分离；**禁止装饰性阴影**（卡片/按钮/表格/文本零 box-shadow）；允许至多一处功能性阴影（浮层投影），且必须在 token 中显式定义或显式置空
- 搜索框：pill、高 44px、左搜索图标（muted）、右 ⌘K 键帽（对基线 §24 的有意变更：圆角 9px → pill；高度与快捷键不变）
- 按钮语法：主操作=pill+强调色（明 #0066cc/暗 #2997ff）；次级=8px utility 或 ghost（hairline 描边+正文色）；按压统一 `scale(0.95)`；焦点统一 2px 焦点环
- 触控/点击目标：行内操作按钮最小点击区 ≥28×28px（桌面密度适配，低于规范 44px 标准的裁剪由架构师验证可用性）

### 4.4 密度适配裁定（Apple 营销语言 → 数据工具）

| 维度 | Apple 规范原文 | PortGate 裁定 |
|---|---|---|
| 正文字号 | 17px | 表格/统计/抽屉正文 13px 档；页面标题保持 600+负字距 Display 语法 |
| 行高/留白 | 80px section、超低密度 | 表格行高 44–60px（目标 48px）；条带留白 12–24px 档 |
| 分区方式 | tile 色块交替 | 页眉/统计/表格用次级面色带区分，非全幅 tile |
| 阴影 | 仅产品图一影 | 零装饰阴影，浮层 scrim+hairline |
| 大写表头 | nav 用 12px 大写 | 表头双语双行堆叠（§6-3，v1.1 用户-directed 变更）：EN 大写主行为合法数据形态（出自常量表，CSS 层禁 `text-transform: uppercase`）+ CN 辅助行（11px 次要色） |

## 6. 文案策略（对盘点 #8 的裁定；v1.1 数据指标标签双语标注口径）

总原则：**控件与状态文案中文为主，数据指标标签双语标注（英文为主行 + 中文辅助行），技术标识符保留英文原文，全应用一套规则、落常量表统一管理**（便于自动化断言与后续 i18n）。

> **v1.1（2026-09-23，用户-directed）**：数据指标标签由「中文为主」修订为「双语标注」口径；变更来源 = 用户交付后反馈，经实施方案 v1.2 §11.5 登记并审查闭环后由 PM lane 回流同步（用户原话见 §1，决策记录 D-UI-10）。第 3/4 条更新为双语形态，新增第 9/10 条；第 1/2/5~8 条与格式规则不变。

1. **控件与导航标签用中文**：搜索、结束进程、强制结束、复制命令、打开项目目录、历史、设置、监控中、扫描失败等（纯中文保留域，不变）
2. **技术标识符与数据值保持英文原文、不改写大小写**：TCP、UDP、PID、PPID、LISTEN、ESTABLISHED、⌘K、Docker、macOS 等
3. **表头双语（两行堆叠 EN+CN）**：EN 大写主行（合法数据形态，出自常量表，非 CSS transform）+ CN 辅助行（11px/400 次要色）——PORT 端口 / PROCESS 进程 / APP 应用 / ADDRESS 地址 / UPTIME 运行时长 / ACTION 操作（PROJECT 并入进程列，见 D-UI-04）；历史表头 PORT 端口 / PROCESS 进程 / INTERVAL 时间区间 / DURATION 时长
4. **统计标签双语**：`Ports 端口数 46 · TCP 38 · UDP 8 · Exposed 对外 5` 形态（EN 主标签 + CN 辅助内联，TCP/UDP 豁免中文；数字 tabular；「对外」为 Exposed 的中文辅助）
5. **暴露术语分级**：列表与统计用短标签「对外 / 仅本机」；详情 Drawer 保留完整定义「Exposed 对外监听 / Local 仅本机」（基线 §7 语义不变，含「对外监听 ≠ 公网可达」提示）
6. **格式规范**：时长秒位为零则省略（`2m`）；省略号 `…`；连接箭头 `→`；中文语境中文标点
7. **中点规则**：`·` 仅并列同类短元数据；键值对用标签式，禁止 `·` 连接异质维度（修正 `· 22415` / `· LISTEN` 混用）
8. **占位符**：`搜索端口、PID、进程、应用、项目、路径、命令…`（保持，符合本规则）
9. **双语标注规则与豁免域（v1.1 新增）**：适用域 = 数据指标类标签（表头、统计标签、抽屉分区标题与字段标签、设置标签）——英文为主行（计算机专业惯例；形态不改写：表头/分区标题大写、字段标签原样大小写）+ 中文辅助行（11px/400、次要文本色，字号更小、颜色更浅）；展现形态：表头两行堆叠（EN 上 CN 下）、抽屉分区标题与字段标签同行内联、统计条与设置标签内联——本条将用户已认可的值层双语形态（第 5 条「Local · 仅本机」）对齐扩展至标签层。豁免域：TCP/UDP/CPU 不配中文（判据 = 缩写是否已脱离英文原词被通用理解）；Exposed 不豁免（非通用缩写且安全含义需中文锚定「对外」）、PID/PPID 不豁免（「进程 ID / 父进程」有理解增益）；值域维持既有形态（`1s / 2s / 5s`、TCP/UDP/LISTEN/ESTABLISHED 等数据值）。抽屉 18 字段与五分区的中英定名以方案 v1.2 §8.2 双语定名对照总表为断言基准（中文名逐字采纳用户反馈草案，遵守 Last Seen ≠ Last Active）
10. **纯中文保留域（双语标注不适用，不变）**：按钮（结束进程/强制结束/复制命令/打开项目目录/取消/清空搜索）、Tab（当前/历史）、状态（监控中/扫描失败）、空态文案、tooltip（浅色/深色、保护原因）、确认弹窗与拒绝文案、搜索 placeholder、品牌名 `PortGate · 端口门禁`——用户反馈明确限定「这些指标」（数据指标类标签），控件与状态语境的中文主语境不变

搜索与高亮不受文案规则影响（检索对象是数据值本身，HighlightText 行为不变）。
